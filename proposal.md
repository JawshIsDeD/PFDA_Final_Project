# PFDA Final Proposal: Tetris Gameplay Loop

## Repository
<https://github.com/JawshIsDeD/PFDA_Final_Project.git>

## Description
I plan to make a working version of Tetris. I want it to include background music, a pause menu, starting countdown, and any other quality of life additions to the game that I would want that would make it enjoyable to me.

## Features
- Feature 1
	- Start and pause menu.
- Feature 2
	- Background music and what the next tetris piece will be with a small preview.
- Feature 3
	- Points that are added after completing each row, getting the highest points I can before there is no more room for the pieces to fit, resulting in a GAME OVER Screen.

## Challenges
- Need to know how to impliment a start and pause menu (COOL EXTRA- having an image show up during the pause menu so it is not just black and white text).
- Importing pygame in order to run/play the game.
- Will be learning how to pause/play a game sequence with background music and any visual flair I can add (I have never made a game a day in my life).
